## Modificações Realizadas

Foram realizadas diversas modificações no jogo com o objetivo de personalizar sua aparência, ajustar seus elementos e alterar alguns aspectos da jogabilidade.

### Alterações realizadas:

* **Título do jogo:** alterado de **“Neon Surge”** para **“Surge Evolution”**.
* **HP dos inimigos:** ajustado para modificar a quantidade de vida dos inimigos.
* **DMG dos inimigos:** alterado para modificar o dano causado pelos inimigos ao jogador.
* **SPD dos inimigos:** ajustado para modificar a velocidade de movimentação dos inimigos.
* **Cores dos inimigos:** modificadas para melhorar a diferenciação visual entre os inimigos.
* **Vida do jogador:** alterada para modificar a quantidade de vida disponível durante a partida.
* **Fire Rate:** ajustado para modificar a velocidade entre os disparos do jogador.
* **Float Board:** modificado como parte da personalização dos elementos do jogo.
* **Cor do cenário:** alterada para modificar a aparência visual do ambiente do jogo.

As modificações foram realizadas para personalizar o jogo, testar diferentes configurações e observar como as alterações nos parâmetros influenciam a experiência e a jogabilidade.
